# Repository conventions

- Keep one folder per exercise, with `starter/`, `my_solution/`, and `reference_solution/`.
- Write new instructions and comments in English. Preserve imported user code unless asked to change it.
- Use Python scripts or Jupytext percent-format `.py` files. Do not commit `.ipynb` files unless explicitly requested.
- Never replace the learner's work with reference solutions.
- Keep datasets, generated plots, checkpoints and credentials out of Git.
- Prefer short, reproducible experiments and meaningful validation over extensive infrastructure.
